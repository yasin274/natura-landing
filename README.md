# Natura — лендинг мебельного бренда

Адаптация присланного референса (Natura Furniture) под русский язык и кириллическую типографику.
Чистый HTML/CSS/JS, без сборки и зависимостей.

```
natura-landing/
├── index.html              # вся разметка + SVG-спрайт иконок
├── assets/
│   ├── css/styles.css      # 19 секций, всё на CSS-переменных
│   └── js/main.js          # интерактив, ~250 строк
└── photos/                 # сюда кладутся реальные фото (см. ниже)
```

## Запуск

Открыть `index.html` напрямую нельзя — при `file://` браузер не подхватит
относительные пути к CSS/JS. Нужен любой локальный сервер:

```bash
python -m http.server 8123 --directory "C:/Users/Asus/Desktop/Projects/natura-landing"
```

Затем `http://localhost:8123`.

## Что сделано для кириллицы

Это не перевод текста, а перенастройка типографической системы — кириллица
ведёт себя иначе, чем латиница, и макет под неё нужно перебирать.

### Шрифты

| Роль | Гарнитура | Почему |
|---|---|---|
| Заголовки | **Playfair Display** | Полный набор `cyrillic` + `cyrillic-ext`, высокий контраст штриха как в референсе. Русская «Ж», «Щ», «Ф» нарисованы, а не синтезированы. |
| Текст и UI | **Manrope** | Кириллица от автора гарнитуры, 4 реальных веса — нет фальшивого жирного. |

В запросе к Google Fonts явно указан `subset=cyrillic,cyrillic-ext,latin`.
Оба фолбэка (`Times New Roman`, `Segoe UI`) тоже кириллические — при отвале
CDN страница не рассыпается.

### Метрики (`:root`)

| Токен | Значение | Отличие от латинского макета |
|---|---|---|
| `--lh-display` | `1.14` | Для латиницы хватило бы `1.02–1.06`. У кириллицы почти нет выносных элементов, строки визуально «липнут» — нужен воздух. |
| `--lh-h2` | `1.18` | То же. |
| `--lh-body` | `1.65` | Однородный x-height утомляет глаз быстрее. |
| `--ls-display` | `-0.006em` | В референсе плотный трекинг (`-0.04em`). По-русски он склеивает «ЖШЩ» — сведён почти к нулю. |
| `--ls-caps` | `0.13em` | Прописная кириллица шире латинской: без широкого трекинга «ХИТЫ ПРОДАЖ» читается как одно слово. |

На экранах ≤720px интерлиньяж заголовков дополнительно поднят
(`--lh-display: 1.18`) — длинные русские слова дают больше переносов строк.

### Длина строки и раскладка

- `.lead { max-width: 46ch }` — русский текст на 10–15% длиннее английского,
  поэтому мера короче, чем была бы в оригинале (там ~60ch).
- Кнопки — `min-height: 48px` + паддинги, **без фиксированной ширины**:
  «Смотреть коллекции» вдвое длиннее `Explore Collections`.
- `.cat__name` — кегль ниже базового: «Хранение», «Для улицы» не влезают
  в подпись категории на обычном размере.
- `text-wrap: balance` на заголовках, `pretty` — на цитатах.
- `.floatcard__title` обрезается через `ellipsis`, а не ломает карточку.
- `hyphens: manual` — автопереносы в русском срабатывают некорректно без
  словаря; вместо них расставлены `&nbsp;`.

### Микротипографика

- **Неразрывные пробелы** после коротких предлогов и союзов: `для&nbsp;каждого`,
  `и&nbsp;безупречный`, `в&nbsp;каталог`, `о&nbsp;нас`. Предлог не должен
  оставаться в конце строки — базовое правило русского набора.
- **Разряды и валюта**: `89&nbsp;900&nbsp;₽` — неразрывные пробелы и в разряде,
  и перед знаком рубля.
- **Табличные цифры**: `font-variant-numeric: tabular-nums` на ценах, рейтингах
  и счётчике корзины — колонки не «прыгают» при смене значений.
- **Десятичная запятая**: `4,9`, а не `4.9`.
- **Кавычки-ёлочки**: `«Диван „Луна“»`. В JS есть `productName()` — при
  подстановке названия в тост внутренние `«»` заменяются на `„“`, потому что
  вкладывать одинаковые кавычки нельзя.
- **Дата и телефон** в локальном формате: `12 мая 2026`, `+7 (800) 123-45-67`.
- `<html lang="ru">` — включает правильные правила переноса и словари проверки.

## Дизайн-система

Палитра снята с референса, контраст проверен по WCAG AA:

```css
--olive:  #4d5d3a   /* акцент, кнопки, баннеры — 6.5:1 с белым */
--cream:  #faf8f4   /* фон страницы */
--sand:   #ebe4d7   /* поверхности категорий, бейджи */
--ink:    #23231e   /* основной текст */
--muted:  #63635a   /* второстепенный — 5.3:1 на cream */
--gold:   #c8a55b   /* звёзды рейтинга */
--terra:  #a8593a   /* скидки, избранное */
```

Ритм — шкала 4/8/12/16/24/32/48/64/96px, радиусы 8→34px + pill,
три уровня тени, три скорости анимации (150/240/520ms).

## Интерактив

- Липкая шапка со стеклом, тень появляется при скролле
- Мобильное меню: выезжающая панель, затемнение, закрытие по Escape и клику
  вне, возврат фокуса, блокировка скролла body
- Карусели товаров и отзывов: scroll-snap, стрелки с блокировкой на краях,
  перетаскивание мышью, стрелки клавиатуры ←→, точки-индикаторы
- Автопрокрутка отзывов с паузой на hover/focus и при скрытой вкладке
- Избранное, выбор обивки, счётчик корзины с тостами
- Валидация подписки с русскими сообщениями об ошибках, ошибка снимается при
  первом же вводе
- Появление блоков при скролле через `IntersectionObserver`
- Подсветка активного пункта меню по видимой секции

## Доступность

- Контраст текста ≥4.5:1, кнопок ≥3:1
- Все интерактивные элементы ≥44×44px
- `aria-label` на иконочных кнопках, `aria-pressed` на переключателях,
  `aria-live` на счётчике корзины и тостах
- Видимый `:focus-visible`, ссылка «Перейти к содержимому»
- `prefers-reduced-motion` отключает анимации, автопрокрутку и smooth-scroll
- Декоративные SVG — `aria-hidden`, содержательные — `role="img"` + `aria-label`

## Адаптив

Проверено на 375 / 390 / 768 / 1024 / 1180 / 1440px — горизонтального скролла
страницы нет ни на одной ширине.

| Ширина | Что меняется |
|---|---|
| ≤1180 | 4 категории в ряд, 2.15 карточки в карусели, подвал в 3 колонки |
| ≤1024 | Меню в бургер, hero в одну колонку (фото сверху), баннер вертикально |
| ≤720 | 1.28 карточки, преимущества в столбик, «Кабинет» переезжает в меню |
| ≤420 | 3 категории в ряд |

## Как подставить реальные фото

Все фотослоты — это `<div class="ph">` с векторной заготовкой внутри
(тёплые интерьерные иллюстрации, работают офлайн и не ломают вёрстку).

Чтобы заменить на фотографию, добавьте атрибут `data-photo`:

```html
<div class="ph ph--hero" data-photo="photos/hero.jpg" role="img" aria-label="...">
```

`main.js` предзагружает файл и подставляет его фоном только после успешной
загрузки — если пути нет, остаётся иллюстрация. Пропорции слота задаёт
`aspect-ratio` в CSS, кадрирование — `background-size: cover`.

Рекомендуемые размеры: hero — 1600×1240, карточка товара — 800×740,
статья — 700×840, баннер распродажи — 1120×760. Формат — WebP или AVIF.

Не забудьте обновить `aria-label` под реальное содержимое снимка.
