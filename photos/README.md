# Папка для фотографий

Положите сюда снимки и добавьте `data-photo="photos/имя.jpg"` в нужный
`<div class="ph">` в `index.html`. Подробнее — в корневом README, раздел
«Как подставить реальные фото».

Ожидаемые файлы и размеры:

| Файл | Размер | Где используется |
|---|---|---|
| `hero.jpg` | 1600×1240 | Главный блок |
| `sofa.jpg` | 800×740 | Карточка «Диван «Луна»» |
| `table.jpg` | 800×740 | Карточка «Обеденный стол «Хейвен»» |
| `chair.jpg` | 800×740 | Карточка «Кресло «Каса Лаунж»» |
| `sideboard.jpg` | 800×740 | Карточка «Комод «Мило»» |
| `sale.jpg` | 1120×760 | Баннер распродажи |
| `post-dining.jpg` | 700×840 | Статья про обеденную зону |
| `post-bedroom.jpg` | 700×840 | Статья про спальню |
| `post-trends.jpg` | 700×840 | Статья про тренды |

Формат — WebP или AVIF (для веса), JPEG как фолбэк. Пока файлов нет,
на их месте показываются векторные заготовки.
